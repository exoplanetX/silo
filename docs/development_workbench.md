# SILO 本地开发工作台

工作台在 Codex 内置浏览器旁呈现项目状态、目标与证据，读取当前仓库，不修改求解器。

## 启动与使用

从项目根目录运行：

```powershell
& .\.venv\Scripts\python.exe scripts/workbench.py
```

打开 <http://127.0.0.1:8765>；也可用 `--port 8766` 指定另一个端口。
服务只监听 `127.0.0.1`，停止时在运行终端按 Ctrl+C；重启 Codex 或电脑后需重新启动服务。
只需 Python 3.10+ 标准库，无新增第三方包、构建步骤、API key、CDN 或云端发布。

六页分别为：开发总览、目标与阶段、求解器评价、任务与证据、开发伴学、版本与交付。
导航可直接定位 `/#evaluation` 等页面；搜索支持任务编号、日期、标题和学习主题。
页面每60秒读取一次资料；打开阅读/上下文窗口或正在输入时暂停自动刷新。
“刷新数据”重新读取文件与本地 Git，不执行测试、实验或 fetch。

## 阅读与 Codex 讨论

来源按钮在内置阅读器中呈现原文件；教学正文、练习和解答直接来自 `learning/`。
Markdown 支持标题、表格、列表、链接和代码；数学公式由本地文本转换器生成浏览器原生 MathML。
支持 L0016 实际使用的上下标、分式、矩阵、转置/逆、求和和不等式，无 CDN 或额外服务。
未知语法显示明确的原文回退，可切换到有行号的完整来源；不执行 TeX 宏、HTML 或脚本。

### L0016 可靠求解器专题

从开发伴学首页进入，或直接打开 <http://127.0.0.1:8765/#learning/L0016>。
在 URL 后增加 /R01 至 /R08 可直接定位对应单元。十节完整正文、练习和解答直接读取
learning/lessons/L0016-reliable-solver/；练习与解答分别呈现，八道解答由读者主动展开。
页面显示教材本身的讲解版本、verified_code、verified_on，不用打开日期替代教学核验身份。

S0–S4 演示读取 web_outline.json 的精确有理数据，显示逐项累积修改、旧点的可行性和复用条件。
eta 演示从 L0016-E03 提取两个矩阵与右端，使用固定2×2有理运算展示普通/转置顺序、
中间向量和当前方程残差；错误顺序明确标注并显示非零残差。浏览器不调用 solver 或 examples.py。
examples.py 只作为可读来源；其运行核对由本合同执行一次，网页不新增命令执行接口。

本专题页面阅读中暂停60秒自动刷新，避免重置阅读位置和已展开的解答；手动刷新会重读规范资料。
当前定位、规模/性能和候选交付卡片按2026-10-25已签收评估同步。warm4的3.503361仅适用于
指定源/输入/本机该轮五重复；同源其他轮超时、附加宿主观察器0样本以及跨运行稳定性未确立均保留。
只更新本合同实际核对来源的映射与哈希，其他旧来源变化提示仍保留。

“生成讨论上下文”“查看档案”等入口整理当前对象、HEAD、读取时间、来源哈希及原文节选。
可输入自己的问题，再点击复制并粘贴到 Codex 对话。若浏览器限制剪贴板，会选中文本提示 Ctrl+C。
节选最多四个文件、各45行；对完整结论仍应继续读取来源全文。
此操作不调用额外模型、不自动发送消息，也不启动执行、修改状态或批准任务。

最近变化使用浏览器本地存储比较上次浏览的 HEAD、已登记来源摘要与目录数量。
首次打开建立基线；清理浏览器存储后重新开始。浏览器禁用存储不影响实时读取。

## 边界与验证

网页提供只读 GET 接口；不提供任意命令、求解运行、仓库写回、阶段审批或推送。
文件阅读限制为指定文本目录，拒绝越界、符号链接逃逸、环境与 Git 私有文件。
它是个人本机工具，不作为多用户网络服务部署；来源文本按文本处理，不执行内嵌 HTML。
本地 Git 同步差异只使用缓存 `origin/main`，不能证明即时远端状态。

确定性检查：

```powershell
& .\.venv\Scripts\python.exe -m pytest tests/unit/test_workbench.py -q
node --check scripts/workbench/app.js
& .\.venv\Scripts\python.exe scripts/check_project_structure.py
```

[任务合同](../tasks/codex/20261023-01-01_development-workbench.md)和
