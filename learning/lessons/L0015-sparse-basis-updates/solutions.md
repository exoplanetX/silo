# L0015 解答

**E01。** 正向解先LU，再E1逆、E2逆；转置解先E2转置逆、E1转置逆，再LU转置。
右端(1,0)在该对称最终B下均给(2,−1)，错误转置顺序给(1,−1)。

**E02。** 第二式减第一式的两倍得epsilon*y=0。epsilon非零，所以y=0，x=1，目标0。
数值主元过小只能触发恢复或保守失败，不能改变严格方程组。

**E03。** 旧比率为(1,.5)，选第二行；新比率为(.5,2)，应选第一行。
发生任何因子重构后，撤销尚未提交的方向、权重和离基选择，重算基本值、对偶、
约化成本、方向与比值。提交时再次确认代次；无法可靠恢复时返回数值失败。
该代次流程已由4fc79d4及注入测试核对；它保证选择量一致，
基本解的前向误差与接受pivot后的数值可行性仍有未关闭义务。

**E04。** 单元测试的输入分母和路径不同。容量失败仍在固定分母中；更新率只说明机制，
主比值须在全部160状态、五次配对重复的20次修改段完整计时后计算，包含编辑和核验；
初始化另列，含导入及初始化的总比也须报告，且60秒保护覆盖全过程。

**E05。** 选择步长为max(−1e−15,0)/1=0；实际eta坐标使用rho=−1e−15，
故y=(−1e−15,−2e−7)。旧基本向量在默认原primal门内，新向量的第二项超出该门。
代入新基可得B_new*y=b，后向残差为0；残差条件和分量可行性条件须分别满足。

**E06。** 基系数相同不代表新因子generation保留旧浮点基本解。候选门只验证了提交时的g；
同基重构必须在新generation的B/BT完整state稳定并通过原primal门后才发布。
若旧状态仍可信，可丢弃失败的新因子并拒绝触发列；若旧残差已失败，恢复也失败时应保守退出。
该义务在a4eccb1尚未实现；第7轮fc33014新增三处主动同基事务并通过组件核验，固定容量仍失败。
同基重构没有替换基列，故成功换基与eta计数均不增加；实际分解/求解与并存峰值照实增加。
拒绝触发列只说明安全门失败，不能作为约化成本支配证明，也不能据此宣称最优。

**E07。** 第一行与x>=0共同强制x=0，精确最优为0。第二行的基本值1e4不能替第一行
提供1e-3数量级的可行余量，否则选择x=1也可能通过放大的内部预测门。
对零坐标的行级余量约为gamma，除以1e-8只给约1.421e-6的选择窗口，排除步长1。
工程窗口仍须原始空间目标、primal/dual/KKT及真实候选因子检查，不能宣称全浮点精确最优定理。

**E08。** 初始人工基的Phase-I对偶(-1,-1)，约化成本(-1,0)。第1列换出第1个人工变量后，
对偶(-1/2,-1)，第2列约化成本1/2；当前点0和人工目标0仍达到可行上界。
再用第2列换出剩余人工变量，得到无人工列的基A与零解，随后以原目标重算Phase II。
若剩余人工坐标为(1.5eps,-0.75eps)，负坐标在逐分量容差内，有符号和0.75eps会通过，
正部质量1.5eps则必须拒绝。清理失败不能沿用一个对偶不可行基签发Farkas。

**E09。** 基(x,w)给(-1.1e-7,2.5)，全局门3.5e-7内；原变量零下界的逐分量门约1e-7，
因此x仍违规。让y进入后x=0、y=1.1e-7、w=2.5，目标-y=-1.1e-7。
把非slack部分记作A0*z0，若标准行残差q=b-A0*z0-sigma*s，则原侧违规为(-s-sigma*q)/row_scale。
忽略q会在阈值附近漏掉真实原侧违规。mapped-only是浮点分量门，缺少进入列不能自动推出
原始模型严格不可行，故保守数值失败；Farkas仍须原全局路径与原始精确核验。

**E10。** beta0到beta1再到beta2均不同、前两步theta=0，随后到beta3正进展，已经说明
连续退化不蕴含循环。实际重复有序语义基时启用sticky Bland进入列回退，给出离散循环证据。
同一phase因子重构只改变数值表示，应保留历史；新模型公开求解或phase改变了定价问题，
应重置旧历史。Harris出基没有变成Bland最小下标规则，故不声称经典有限pivot定理。
