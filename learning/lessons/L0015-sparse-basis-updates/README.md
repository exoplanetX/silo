# L0015｜稀疏基、eta更新与重构后的状态一致性

## 1. 问题与学习目标

反复求解相邻LP时，可复用的对象包括基的语义身份、LU及其更新链。本篇解释
三者分别保存什么，以及一次重构为何要求重新计算尚未提交的比值检验。
当前正文是SP2未通过时保存的伴学草稿；组件通过范围和容量失败在第6、8节分开记录。

## 2. 前置知识、符号与假设

沿用L0012的最大化标准形 (Az=b,z\ge0)。非奇异基为 (B)，

\[
x_B=B^{-1}b,\quad \lambda=B^{-T}c_B,\quad r=c-A^T\lambda.
\]

稀疏矩阵仅存非零及索引。LU用于线性方程组；SILO仍负责Phase I/II、定价、
换基和终止。基础dense路径只依赖NumPy，显式sparse路径才加载SciPy。
原始模型中的变量界、行区间、常数及目标方向由索引仿射映射恢复。

## 3. 手算例子

从 (B_0=I_2) 出发，先用 ((1,1)^T) 替换第1列，再用 ((1,2)^T) 替换第2列。
两次方向都是 ((1,1)^T)，所以

\[
E_1=\begin{pmatrix}1&0\\1&1\end{pmatrix},\quad
E_2=\begin{pmatrix}1&1\\0&1\end{pmatrix},\quad
B=B_0E_1E_2=\begin{pmatrix}1&1\\1&2\end{pmatrix}.
\]

解 (B^Ty=(1,0)^T) 时，先作用 (E_2^{-T}) 得 ((1,-1)^T)，
再作用 (E_1^{-T}) 得 ((2,-1)^T)，最后解 (B_0^T)。
若把eta转置逆按正向顺序作用，会得到错误的 ((1,-1)^T)。

## 4. 原理推导与正确性依据

进入列为 (a)，替换基位置 (p)，令 (d=B^{-1}a\)、

\[
E=I+(d-e_p)e_p^T,\qquad B_{new}=BE.
\]

对向量 (v)，(E^{-1}v) 的第 (p) 项为 (v_p/d_p)，其余项为

\[
(E^{-1}v)_i=v_i-d_i v_p/d_p.
\]

转置逆只改变第 (p) 项：

\[
(E^{-T}v)_p=(v_p-\sum_{i\ne p}d_i v_i)/d_p.
\]

因此B解先做基LU，再按时间正序作用eta逆；B转置解先按时间逆序作用eta转置逆，
再做基LU转置解。实现保存完整实际方向，不通过截断小系数换取稀疏性。
最多20次更新，之后重构当前实际B。每次解都核对当前B残差；两次精化仍失败时，
允许一次当前B重构，继续失败则返回数值失败。

这项线性代数恒等式不保证浮点单纯形始终可行。进入方向与基本值共同决定
最小比值；因子重构改变了其数值结果时，旧离基行必须作废。应维持同一代次：

\[
g(x_B)=g(r)=g(d)=g(\text{ratio})=g(\text{commit}).
\]

产品4fc79d4已用generation/token/retry关闭恢复型重构后的未提交选择一致性。
链限重构保留已验证方向并原子提交，成功后重置定价，下一外层重算；它不会重算新方向后沿用旧比率。
这项不变量仍不能代替基本解和方向的前向可行性核验，容量失败在第8节单列。

MIP子节点只能导入被动基，新建其私有因子。

## 8. 局限、反例与失效条件

两条等式 (x+y=1\)、(2x+(2+\epsilon)y=2\) 在非零二进制

\(
\epsilon=2^{-39}
\)

时严格推出 (y=0)。用主元容差把第二行当作冗余，会把最小目标 (-y) 错报为−1。
删行需要原始二进制方程的精确依赖核验；核验超预算时保守失败。

若 (x_B=(1,1)\)，旧方向为 ((1,2)\)，旧离基行为第二行。重构后方向变为

\(
(2,0.5)
\)

时，第一行才是真实阻塞行。沿用旧第二行会给步长2，使第一基本值变成−3。
该类“重构后提交旧离基行”已由4fc79d4及注入测试关闭。
此前两容量诊断分别在3963次换基后丢失可行性、5057次换基后达到25秒诊断时限；
追加正式复验则在3963和13830次换基后都丢失可行性，原始实例与阈值未变。
它们是失败证据，不能算作规模或加速通过。

后向残差小不保证分量非负。取B的两行为(1,1)、(1,1+epsilon)，
真实点(1,1)与不可行点(−1,3)的行残差仅为(0,2epsilon)。
第4轮877058d补齐末pivot观测：两CAP的零步预测在原容差内，而fresh新基解及同基重构后
都失可行，所有后向残差仍过门。阈值没有缩小，重构本身也未恢复。

应区分比率选择使用的步长与候选基的代数坐标。对于离基位置r，后者满足

\[
\rho=x_{B,r}/d_r,\qquad y_r=\rho,\qquad y_i=x_{B,i}-\rho d_i\quad(i\ne r).
\]

当旧基本值为容差内的负数时，选择用的max(x_{B,r},0)/d_r可为0；把0代入候选坐标
会遗漏被放大的误差。FLOW观测的rho约−1.93346e−14，乘失败行方向−2.34851e7，
将原基本值−2.97146e−8变为约−4.83789e−7，与实际新基解吻合，超过原约2e−7门。
TRANS的rho约−1.76751e−4，进入坐标自身就不满足原约4.85714e−7门。

小例可取旧B=I、x_B=(−1e−15,0)、方向d=(1,−2e8)。选择步长为0，
候选基实际基本向量却为(−1e−15,−2e−7)，在默认原基本容差下失败。
这说明候选坐标需独立核验；第5轮正据此推导提交前的raw-candidate门，尚未声称容量通过。
