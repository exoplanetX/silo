## 2. 前置知识、符号与假设

沿用L0012的最大化标准形 (Az=b,z\ge0)。非奇异基为 (B)，

\[
x_B=B^{-1}b,\quad \lambda=B^{-T}c_B,\quad r=c-A^T\lambda.
\]

稀疏矩阵仅存非零及索引。LU用于线性方程组；SILO仍负责Phase I/II、定价、
换基和终止。基础dense路径只依赖NumPy，显式sparse路径才加载SciPy。
原始模型中的变量界、行区间、常数及目标方向由索引仿射映射恢复。

## 3. 手算例子

从 (B_0=I_2) 出发，先用 ((1,1)^T) 替换第1列，再用 ((1,2)^T) 替换第2列。
两次方向都是 ((1,1)^T)，所以

\[
E_1=\begin{pmatrix}1&0\\1&1\end{pmatrix},\quad
E_2=\begin{pmatrix}1&1\\0&1\end{pmatrix},\quad
B=B_0E_1E_2=\begin{pmatrix}1&1\\1&2\end{pmatrix}.
\]

解 (B^Ty=(1,0)^T) 时，先作用 (E_2^{-T}) 得 ((1,-1)^T)，
再作用 (E_1^{-T}) 得 ((2,-1)^T)，最后解 (B_0^T)。
若把eta转置逆按正向顺序作用，会得到错误的 ((1,-1)^T)。

## 4. 原理推导与正确性依据

进入列为 (a)，替换基位置 (p)，令 (d=B^{-1}a\)、

\[
E=I+(d-e_p)e_p^T,\qquad B_{new}=BE.
\]

对向量 (v)，(E^{-1}v) 的第 (p) 项为 (v_p/d_p)，其余项为

\[
(E^{-1}v)_i=v_i-d_i v_p/d_p.
\]

转置逆只改变第 (p) 项：

\[
(E^{-T}v)_p=(v_p-\sum_{i\ne p}d_i v_i)/d_p.
\]

因此B解先做基LU，再按时间正序作用eta逆；B转置解先按时间逆序作用eta转置逆，
再做基LU转置解。实现保存完整实际方向，不通过截断小系数换取稀疏性。
最多20次更新，之后重构当前实际B。每次解都核对当前B残差；两次精化仍失败时，
允许一次当前B重构，继续失败则返回数值失败。

这项线性代数恒等式不保证浮点单纯形始终可行。进入方向与基本值共同决定
最小比值；因子重构改变了其数值结果时，旧离基行必须作废。应维持同一代次：

\[
g(x_B)=g(r)=g(d)=g(\text{ratio})=g(\text{commit}).
\]

产品4fc79d4已用generation/token/retry关闭恢复型重构后的未提交选择一致性。
链限重构保留已验证方向并原子提交，成功后重置定价，下一外层重算；它不会重算新方向后沿用旧比率。
这项不变量仍不能代替基本解和方向的前向可行性核验，容量失败在第8节单列。

同基主动刷新还需一个发布不变量。设旧状态为
\(S_g=(B,F_g,g,x_B,\lambda,r)\)，并已通过当前代次的完整残差、有限性及原primal门。
在私有因子上重构同一个B，重新形成完整的\(\widehat S\)；只有整组状态同代且通过原门才发布。
核验失败时，保留仍可信的\(S_g\)，拒绝触发安全失败的进入列；全部改善列被拒绝时保守失败。
由两分支分别保持已验旧状态或发布已验新状态，可知每个继续定价点都保有通过原数值门的完整状态。
这是浮点验收不变量，不是精确可行性的额外定理，也不保证存在另一列能安全换基。

这一推理的前提是旧状态仍可信。若旧因子已违反残差门，强制恢复失败后不能恢复使用它；
此时保守退出。主动刷新只重建数值表示，成功换基数、eta更新数与iteration均保持；
其实际LU/求解、被拒绝试算和双LU并存峰值仍须计入成本。

### 行级选择窗口与真实基本坐标

稳定主元可能位于严格最小比值之外，但所有正方向分量仍是阻塞约束。
令当前原始可行容差为\(\tau=\epsilon_p(1+\|x_B\|_\infty)\)，内部固定工程常数
\(\gamma=64\,\mathrm{eps}_{64}\)，行级余量取

\[
\delta_i=\min\{\tau,\max(-x_{B,i},0)+\gamma(1+|x_{B,i}|)\}.
\]

第一遍用所有\(d_i>0\)计算\(\bar\theta=\min_i(x_{B,i}+\delta_i)/d_i\)；
第二遍仅在选择比值\(\max(x_{B,i},0)/d_i\le\bar\theta\)的安全主元中确定次序。
无关的大坐标不能扩大某个非负零坐标的行级余量。实现用等价非负headroom避免消减及上溢。
这一步只生成候选；真实新基坐标仍是\(\rho=x_{B,r}/d_r\)、\(y_r=\rho\)、
\(y_i=x_{B,i}-\rho d_i\)，必须通过预测及实际候选因子的原门。
\(\gamma\)没有给出所有浮点输入上的精确前向误差保证。

当前每个进入列/同一语义基最多实际开始两次完整私有试算，包含可选同基刷新和新基候选；
generation重启不补额。预测的向量检查与完整LU/状态试算分别计数，拒绝集合不能推出最优。

### 人工变量清理保持点的可行性

Phase I最大化\(-\sum a_i\)，而\(a_i\ge0\)，所以可行目标的上界为0。
零人工量的原始可行点已经达到此上界；清理的任务是换出值为零的基本人工变量。
一次退化换基可以使新的基失去Phase-I对偶可行性，同时保留同一最优点。

手算\(A=\begin{pmatrix}-2&-1\\1&1\end{pmatrix}\)、\(b=0\)、\(x\ge0\)。
唯一可行点为0。初始人工基为单位阵、Phase-I对偶为\((-1,-1)\)，两列约化成本为\((-1,0)\)。
用第1列换出第1个人工变量后，基为\(\begin{pmatrix}-2&0\\1&1\end{pmatrix}\)，
基本成本为\((0,-1)\)，对偶为\((-1/2,-1)\)，第2列约化成本变成\(1/2\)。
点和人工目标仍为0，因而可继续清理。

实现逐步核对有限性、当前B同代、原坐标primal门，以及
\(\sum_{i:\,B_i\text{为人工列}}\max(x_{B,i},0)\le\epsilon_p\)。
正部求和避免负容差坐标抵消正人工量。每次换基后立即检查，包括最后一次；
失败给数值失败。Farkas只保留在Phase-I优化终点具有对偶证明的路径上。

### dual退出的原空间分量门与定价回退

全局基本值尺度不能代表每个原变量的边界。例如\(x_B=(-1.1\times10^{-7},2.5)\)
在\(\epsilon_p=10^{-7}\)的全局门\(3.5\times10^{-7}\)内，但第一项的零下界
只允许约\(10^{-7}\)的误差。对于\(x-y=-1.1\times10^{-7}\)、\(w=2.5\)、
最大化\(-y\)的模型，基\((x,w)\)对偶可行，却仍须以y换出负的x。

当前实现保留原全局负行规则，仅在准备宣告dual最优时恢复当前原空间点，按实际有限bound
及逐分量分母补查。结构变量考虑column scale；自由拆分变量没有原始有限bound时不虚构约束。
对标准形slack，令\(q=b-Az\)、实际列系数\(\sigma\in\{-1,1\}\)，其原侧违规为

\[
\frac{-x_{B,i}-\sigma q_r}{\mathrm{row\_scale}_r}.
\]

必须保留非零q及上下侧符号。可定位的负基本坐标继续原dual换基；无法定位或没有安全进入列
时保守数值失败。mapped-only路径不签发Farkas，原全局负行路径仍须原始精确证明。
最后完整KKT继续独立检查；映射门只增加潜在退出处的稀疏乘积，没有新增线性求解。

连续两次零步长也不能证明循环。当前Devex持续工作，只有本phase内重复的有序语义基
才触发sticky Bland进入列回退；factor重构不清空该历史，新的公开求解和phase会清空。
Harris出基仍按稳定性排序，因此不援引经典完整Bland有限终止定理；迭代、时限和资源门保持。
dual退出及pricing的独立policy版本加入私有frame，旧策略缓存不能静默复用。

### 固定工作区中的精确删行依据

人工变量清理遇到近相关行时，已有同代BTRAN只用于提出权重候选。
设缩放基为\(B_s\)，目标基本人工列位于基位置p、物理行t，
\(u=B_s^{-T}e_p\)。以\(R\)表示行尺度，先用\((R_i u_i)/(R_t u_t)\)
恢复未缩放行权重，再按固定分母上限\(10^6\)提出有理候选\(w\)。
接受条件直接针对原始二进制数据：\(w_t=1\)、全部活动非人工列上的
\(w^T N=0\)及偏移后右端\(w^T h=0\)，全部用Fraction精确运算。
实际RHS翻转、变量offset、补界行及slack支持均进入核验；其他基本人工列的支持须为零。

例如\(x+y=2\)、\(2x+2y=4\)取\(w=(-2,1)\)，两列与RHS都精确抵消，
第二行可由第一行恢复。把第二行y系数改成\(2+2^{-39}\)后，残留精确非零，
同一候选必须失败。有限分母候选可以漏掉真实依赖，不能接受虚假依赖。

实现只保留q个权重和n个结构列累计量，在Fraction容器分配前预约
\(2q+2n+32\)格；976行、1列例仅需1986格。65536格、操作数、位数及时限
继续由同一个ProofBudget管理，旧小基精确消去fallback使用其剩余额度。
这避免为大基构造完整有理稠密矩阵。

精确依赖说明删行保持非人工可行方程。删行后minor的精确非奇异结论另需旧B精确非奇异；
数值LU本身不提供这个精确秩前提。实现先私有构造缩减矩阵、真实LU及完整B/BT清理状态，
通过同代、有限性、原primal与正部人工量门后才发布行映射和新基。
新因子失败时不登记已删行，也不产生最优或Farkas结论。

## 8. 局限、反例与失效条件

两条等式 (x+y=1\)、(2x+(2+\epsilon)y=2\) 在非零二进制

\(
\epsilon=2^{-39}
\)

时严格推出 (y=0)。用主元容差把第二行当作冗余，会把最小目标 (-y) 错报为−1。
删行需要原始二进制方程的精确依赖核验；核验超预算时保守失败。

若 (x_B=(1,1)\)，旧方向为 ((1,2)\)，旧离基行为第二行。重构后方向变为

\(
(2,0.5)
\)

时，第一行才是真实阻塞行。沿用旧第二行会给步长2，使第一基本值变成−3。
该类“重构后提交旧离基行”已由4fc79d4及注入测试关闭。
此前两容量诊断分别在3963次换基后丢失可行性、5057次换基后达到25秒诊断时限；
追加正式复验则在3963和13830次换基后都丢失可行性，原始实例与阈值未变。
它们是失败证据，不能算作规模或加速通过。

后向残差小不保证分量非负。取B的两行为(1,1)、(1,1+epsilon)，
真实点(1,1)与不可行点(−1,3)的行残差仅为(0,2epsilon)。
第4轮877058d补齐末pivot观测：两CAP的零步预测在原容差内，而fresh新基解及同基重构后
都失可行，所有后向残差仍过门。阈值没有缩小，重构本身也未恢复。

应区分比率选择使用的步长与候选基的代数坐标。对于离基位置r，后者满足

\[
\rho=x_{B,r}/d_r,\qquad y_r=\rho,\qquad y_i=x_{B,i}-\rho d_i\quad(i\ne r).
\]

当旧基本值为容差内的负数时，选择用的max(x_{B,r},0)/d_r可为0；把0代入候选坐标
会遗漏被放大的误差。FLOW观测的rho约−1.93346e−14，乘失败行方向−2.34851e7，
将原基本值−2.97146e−8变为约−4.83789e−7，与实际新基解吻合，超过原约2e−7门。
TRANS的rho约−1.76751e−4，进入坐标自身就不满足原约4.85714e−7门。

小例可取旧B=I、x_B=(−1e−15,0)、方向d=(1,−2e8)。选择步长为0，
候选基实际基本向量却为(−1e−15,−2e−7)，在默认原基本容差下失败。
这说明候选坐标需独立核验。第5轮已实现raw-candidate门，阻止了原错误提交，
但后续路径仍失可行；第6轮进一步在私有候选因子上核验完整XB/对偶/约化成本。

候选事务只在同一generation的完整state通过后发布新基，并一次性消费该state，
防止B转置求解触发重构后拼接不同代次向量。被丢弃的候选保留实际LU/求解/内存峰值开销，
成功基替换和eta计数只在接受后增加。普通通过toy仍6次线性求解、1次初始LU。

第6轮失败又暴露了同基刷新边界：FLOW末次候选在generation527通过并被消费，
为下一进入列执行的原位raw刷新将其变为528，随后基本解才失可行；TRANS同理为1391→1392。
矩阵CSC身份保持相同，变化的是因子generation。再次重构均未恢复。
因此“换基提交前验证”只是局部不变量；继续primal选择前，任何新发布的同基generation
也必须有完整、通过原门的状态。旧残差已经失败时，不能保留不可信旧因子继续运行。
第7轮获得单独人类授权后，将三类主动同基刷新统一为私有试算，完整state通过后发布。
118组件及172公开集成已通过；该轮唯一固定复验仍未达到容量目标，当时正文保持draft。
该第7轮两例的终止原因已转为所有改善列均被安全门拒绝；未触资源保护，也没有获得最优性证明。
保留可信状态解决了发布安全问题；其后RR02行级窗口补齐选择缺口并通过两固定CAP。
这仍不保证所有病态模型都能安全推进，不能由拒绝集合推出最优。
次数授权与时间余额分别约束执行，组件通过不扩大授权，也不代替容量门。
