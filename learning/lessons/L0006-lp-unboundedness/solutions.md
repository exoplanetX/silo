## L0006-E04

普通浮点乘积舍入成1，a*b-1 得零；原项先转 Fraction 后得到 -2^-54。
浮点0.1略大于精确1/10，故 10*Fraction(0.1)>1；不能据用户可能的十进制意图改写。
float(2^53+1)=2^53，原整数与它相差1。若在转换前做乘法或转成 float，就可能永久
丢掉决定零性/符号的数值信息。

在根目录可独立运行以下标准库程序：

```python
from fractions import Fraction as F

a, b = 1 + 2**-27, 1 - 2**-27
assert a*b - 1 == 0
assert F(a)*F(b) - 1 == -F(1, 2**54)
assert 10*F(.1) - 1 == F(1, 2**54)
assert F(2**53 + 1) - F(float(2**53 + 1)) == 1
delta = F(1 + 5e-10) - 1
assert delta == F(281475, 562949953421312)
assert delta > 0
for power in (-100, 0, 100):
    scale = F(2.0**power)
    assert delta*scale != 0
    assert -F(2**-32)*scale < 0
assert 3*F(1/3) - 1 == -F(1, 2**54)
print('L0006 scalar checks passed')
```

## L0006-E06

精确点(1/3,0)与方向(0,1)给可行射线，故真实无界。有限二进制浮点数可写成
整数除以2的幂；若它等于1/3，则3整除2的幂，矛盾。当前浮点候选因此不能满足精确点
条件。充分条件只保证通过者合法，未声称每个真实无界模型都有能通过的已有候选。

后续实验应固定原始模型族及精确输入语义，分别报告解析有限/无界/不可行分类，
发布各状态数量、真实无界识别率、数值诊断率、候选构造与核验时间。每个成功无界
案例用独立原项算术检查实际候选；有限最优仍需各自最优性证据。真实无界诊断可
反映候选构造的成功边界，不能算作已求得最优或误判有限。高维效率主张需要相应
规模与时间证据；本篇的小模型机制和273项解析测试本身不能支持工业性能主张。
