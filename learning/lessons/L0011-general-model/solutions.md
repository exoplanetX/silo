# L0011 解答

- **L0011-E01**：x=4−z，z>=0，原目标−5+2z，canonical MAX 5−2z。
  z=0对应x=4，原值−5；反射的rc符号随T恢复。
- **L0011-E02**：x−3=(x+y−5)+(2−y)，新上界是原行上侧与y下界之和。
  μ分配到原行上侧及y下界各μ，逆推后再检查原始互补。
- **L0011-E03**：点(0,0)可行，等式dual1使rc0，对偶值0等于原目标0，故所有可行点最优。
  顶点枚举适用条件不满足，空枚举结果没有不可行含义。
- **L0011-E04**：前三种文本表示相同数学整数 9007199254740993。其 float64 舍入值为
  9007199254740992，故先保留 Python 整数，由既有 `input_conversion` 门控明确拒绝；
  小数尾零不提供改变整数值的权限。应使用 Decimal 的数学整数性判据。
  第二个模型的下侧精确为 1e-400，x=0 违反下侧、x=1 可行；该非零端点转 float 会成为零，
  应在解析时拒绝。直接输入与 L/G/E 派生侧共用同一门控。非零 subnormal 如 `5e-324`
  舍入后仍非零，可以按约定的 float64 语义接受。
  对已有整数值 float，输出 `str(int(1e308))` 对应其实际精确整数；短文本 `1e308`
  表示的数学整数与该二进制值不同。范围宽度也从相同已输出端点的 Decimal 值计算。
