# L0008解答与核对依据

## L0008-E01

在旧B可逆且x_B=B⁻¹b>=0时，旧非基与新列均设0，增列模型仍满足原始行与界。
新增列可违反旧对偶约束，所以须重新求本轮RMP。失败warm没有可发布的最终最优依据，
cold回退成功后用其最终MIN result；CG一轮只调用一次公开入口，内部回退不另算外层轮。

若rho是完整域最小rc，delta=min(0,rho)，仅令pi'_conv=pi_conv+delta，则每条路径
rc'=rc-delta>=0。conv是自由等式乘数、全部列系数/RHS为1，其他符号保持，故新对偶
目标D+delta给完整域下界；当前RMP原始点给上界P。基复用不会改变这组数学条件。

## L0008-E02

初轮pi=(2,0)，rc_q=0-2=-2、rc_r=1-2=-1。原标准形基(x,slack_cap)为单位阵，
点(1,0)，q列(1,1)，比率为(1,0)，slack_cap离基、步长0，目标保持2。新对偶可为
(2,-2)，r的rc仍-1，下一轮可加r，目标1。目标保持可能有其他原因，真实退化应观察
实际Phase II、进入/离基比率0与至少一次枢轴；单看目标或flag不能证明。

0枢轴warm表示映射基已满足新模型最优性，仍实际进入Phase II、重新检查定价条件。
程序的诊断用于阅读，版本化测试另观察实际公开RMP、cold、Phase I/II与传入基。

## L0008-E03

seed矩阵的conv/R/C行为(1,1)、(1,0)、(1,0)，秩2；R/C只在当前投影重复。
加o12列(1,1,0)或o21列(1,0,1)后秩3。首轮清理删行，禁止发快照；第二轮cold
保留全部三行、建立全行基；下一轮才warm。完整域令lambda_o12=lambda_o21=1/2，
满足R=C=1/2，成本1.5加c0=-3为-1.5。
仅保留旧投影行会改变新增列约束，不能拿删行后求得的值替代完整原问题答案。

## L0008-E04

RMP最终非最优时，本轮尝试registry与实际outcome保留，pricing和全部界为空；
顶层有效RMP/列集仍属上一成功轮。首次失败无有效RMP，但有一次尝试记录与列注册表。
原始主目标核验先失败时同样保持更早有效轮，pricing尚未调用。

主目标通过且本轮RMP已登记之后，pricing失败或后续candidate/gap失败都可保留当前
有效RMP/registry；本轮P/D/L/g_raw/g/eta及accepted_path全部空，不伪造失败轮新界。
这四类发布点分别测试。seed重构先失败则没有RMP owner、已求解轮或outcome记录。
warm失败/cold成功不改变上述分类；消费cold最终结果后，后续失败仍按实际发布位置处理。

## L0008-E05

每轮S_k不同，最后列集的最优值不能回填此前轮次。独立DFS只从原始图数据累加
Fraction成本/系数；当前集合取该轮不可变registry。枚举正支持，选conv与足够活跃
非conv行，Fraction解小方阵，奇异则跳过，再过滤全部原始EQ/LE/GE与非负性。
冗余EQ可使满行矩阵秩不足，较小支持/独立行组合仍能找到顶点。完整域另以区间
端点或方形t两端点解析核对，不能调用生产基/数值/重构助手给真值。

大c0会吞掉低位，发布P与L可能相等，g_raw=0；原始贡献层g=(2-2)-(-1)=1。
不能用P减c0恢复增量目标，数学目标应比较原始成本乘权重的贡献。以下程序可独立运行：

```python
from fractions import Fraction as F
from math import fsum, ulp

c0 = 2**60
p = fsum([c0, 2])
l = fsum([c0, 2, -1])
assert fsum([p, -l]) == 0
assert fsum([2, -2, 1]) == 1
assert F(2)-F(2)-F(-1) == 1
assert 32*ulp(fsum([abs(1.), abs(-1.)])) == 32*ulp(2.)
print('L0008 contribution and local-scale checks passed')
```

## L0008-E06

外层limit按已求解RMP/定价轮计；第二轮内部warm/cold仍属同一轮。若该轮仍有改善
路径，返回ITERATION_LIMIT，最后一轮不追加未求解列。若已满足成功条件则正常停止。
内层iteration_limit按既有run管理，cold回退次数/枢轴分别记录，不能藏成一个外层调用。

恢复阶段的辅助/验证问题与经济模型目标不同。即使复用同一solver对象，也必须新建
经济RMP owner，首轮snapshot=None且cold，用原成本/c0求解；基快照不得跨这些阶段共享。

288图×三模式=864次CG，60大常数图×三模式=180次CG；每次含若干外层轮，每轮一次
公开RMP调用，内部cold/warm与Phase/枢轴另计。版本化参数测试可每图运行三模式，
故这些运行数不能写成pytest项数。完整域双cold交叉参考也单独统计。

实际省去Phase I是调用路径证据；是否加速还取决于全矩阵重建、解基、定价和回退成本。
本步不开展性能比较，也不证明任意规模/数值尺度稳健性、资源/整数能力或研究创新。
项目原目标继续指挥后续需求，有限DAG链路接通只完成本单限定义务。
