# L0017 解答

**L0017-E01**：移项后x≥3，故x∈[3,5]，最小化在x=3取得目标9。
丢掉常数后最优点仍是3，但返回目标变6，目标比较和包含常数的gap可能错误。

**L0017-E02**：下侧基名band__lower已被变量占用，因此生成band__lower_1；
上侧生成band__upper。两行分别为`x+y≥1`及`x+y≤4`。
若band__lower_1也被原名占用，则继续递增；不能因变量/行类别不同就忽略名称冲突。

**L0017-E03**：二者作为实际二进制有理数不相等，格式比较拒绝。
最优点不变不能证明目标表达式相等。浮点可行性则按原数据和既有残差容差核验；
不能要求数值点精确满足所有有理等式，也不能借该容差放宽文件数据比较。

**L0017-E04**：二者可能稳定重写同一个错误模型，因此仅此检查不能识别。
应从原始payload独立构造含常数的数学预期，另用手写输入与另一解析实现读出数据。
有限例上独立通过仍只覆盖实际例；不能推出所有方言或所有数值范围都正确。
