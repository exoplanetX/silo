## 2. 从数据原语重建定价对象

### 2.1 路径、覆盖与成本

任务 \(j\) 有固定起止时刻，持续时间严格为正。合法连接 \(i\to j\) 满足

\[
\operatorname{start}(j)\ge\operatorname{end}(i).
\]

因此任务结束时刻沿连接严格增加，同一任务在一条路径上最多服务一次。把 \(-\pi_j\) 放在进入任务 \(j\) 的动作上，有

\[
\bar c(P;\pi)=\sum_{e\in P}c_e-\sum_{j\in P}\pi_j.
\tag{A1}
\]

这里的访问前沿 \(L(v)=P(v)\cap F(v)\) 为空，故 \(w=0\)。依据是严格向前的时间连接与服务动作的位置；“任务 ID 唯一”本身不足以推出该结论。

### 2.2 资源字段必须按固定输入解释

本轮按[固定版本实例格式](https://github.com/BartvanRossum/rcsp-benchmark/blob/698703dd98607b3f010bdd859a608be1d3b08133/instances/README.md)执行，并逐条断言：

- SOURCE 的 duration 等于首任务时长，cost 为 duration 加 28,800。
- CONNECTION 的 duration 等于后继任务结束时刻减前驱任务结束时刻，cost 等于 duration。
- SINK 的 duration 与 cost 均为 0。
- 有休息标记的连接满足 \(b_e+a_e+1800=d_e\)；无标记的两个字段均为 \(-1\)。

首任务时长已含在 SOURCE 中，连接时长也已含后继任务，不能再次加任务时长。论文生成描述中的基地移动时间不能未经核验叠加到这一固定输入。三个实例均只有一个 crewBase。

采用仓库 README 的存在性合同：一条 duty 中至少有一个 marked connection 可以作为有效的 30 分钟休息，休息前后各不超过 19,800 秒，总 duty 不超过 34,200 秒。路径可以经过多个 marked connection，只需选出一条有效休息见证。

### 2.3 精确资源状态与见证表示

在完成任务 \(v\) 后保存

\[
x=(v,D,p,h),
\tag{A2}
\]

其中 \(D\) 是累计 duration，\(h\) 是基地，\(p=-1\) 表示尚未选择休息见证；\(p\ge0\) 表示从已选休息结束至当前的累计时间。

未选休息时，可继续不选，要求 \(D+d_e\le19800\)；也可选择当前 marked connection，要求

\[
D+b_e\le19800,\qquad a_e\le19800,
\qquad D+d_e\le34200,
\]

并置 \(D'=D+d_e,p'=a_e\)。已经选择后，后续连接更新为

\[
D'=D+d_e,\qquad p'=p+d_e,
\]

要求 \(D'\le34200,p'\le19800\)。终点只接受已选择的状态。未选状态超过 19,800 秒便无法在后面开始合法休息，因为所有后续 before 和 duration 非负，故提前删除安全。

令 \(q\) 为选定休息开始时的累计 duty time，则

\[
p=D-q-1800,\qquad q=D-p-1800.
\tag{A3}
\]

选择时由 \(d_e=b_e+1800+a_e\) 得到该不变量；此后同时增加 \(D,p\) 保持不变量。因此保存 \((D,p)\) 与保存 \((D,q)\) 完全等价。

**路径投影等价性。** 任意合法 duty 可选择其一个有效休息作为见证，得到可接受状态轨迹；任意可接受轨迹都指明一个满足前后限制的休息。相同任务路径有多个有效见证时，状态图允许多个轨迹；RMP 按覆盖向量去重并保留最低成本。这保证存在性语义，尚未优化全部见证冗余。

本结果分类为 `ALGORITHM_VALIDITY_RESULT`；它支持模型正确性，不主张原创性。

## 3. 为什么小前沿不能支持局部修复结论

### 3.1 一个有绑定资源的反例族

取 \(n\) 个时间层，容量 \(k=\lfloor n/2\rfloor\)。每层可跳过或服务唯一任务 \(i\)，服务消耗一单位资源；第一层另有与任务 1 消耗相同的替代任务 0。状态为

\[
(i,r),\quad 0\le r\le\min(i,k).
\]

所有原始成本为零。参考树到 \((i,r)\) 选择前 \(r\) 个任务，因而是零对偶下的一棵最短路树。任务只出现在各自时间层，故 \(w=0\)；容量 \(k<n\) 在完整路径族中确实绑定。

对 \(i>j\)、\(1\le j\le k\)，从 \((i-1,j-1)\) 服务任务 \(i\) 的扩展弧具有树差分

\[
d_{i,j}=e_i-e_j.
\]

这些差分互异；加上零差分和第一层替代差分，

\[
K=2+kn-\frac{k(k+1)}2=\Theta(n^2),
\qquad N,M_H=\Theta(n^2).
\tag{A4}
\]

只把 \(\pi_0\) 从 0 提高到 1，就使第一层替代弧余量为负。其后继闭包含所有 \(r\ge1\) 状态：

\[
|A|=\sum_{i=1}^n\min(i,k)=N-(n+1)=\Theta(N).
\tag{A5}
\]

这些状态都有使用任务 0 的可行前缀，真实最短距离从 0 变成 \(-1\)。在 \(n=64\) 的有限构造中，\(N=1617,M_H=3137,K=1522,|A|=1552\)，受影响比例约 96.0%。脚本核对了 \(n=4,8,16,32,64\) 的结构计数。

上述精确计数取层状计算图，末层各资源状态为接受状态；如需唯一终点，给它们各接一条零成本边即可，只增加一个状态和 \(O(n)\) 条边，保持全部渐近结论。

交替提高任务 0、任务 1 的相对对偶，可以反复破坏前一棵最短路树；每次失效即重建的策略可每轮重建。这只说明任意回放下没有 epoch 长度保证，不能说明真实 RMP 必然振荡。

**结论：** \(w=0\) 不能单独推出小 \(K\)、小修复闭包或长索引寿命。反例针对声明的状态表示与固定树机制；其他算法可能利用额外结构压缩变化。它不构成一般算法时间或空间下界。分类为 `COUNTEREXAMPLE_FOUND`。

### 3.2 什么条件才可能截断成本传播

一个足够条件是：受影响任务块具有同步出口 \(z\)，相关路径都经过它，在出口处到达相同精确资源/模式状态，且下游没有新的该任务特征；同时，所有需要统一更新的下游路径也必须经过 \(z\)。

此时可在块内重算，到达 \(z\) 的值变化 \(\delta\) 只会给全部相关下游距离加同一个常数。采用延迟势值表示，可把显式重算限制在块内状态与转移，另计边界和维护成本。证明来自任何下游路径都分解为经过 \(z\) 的最优前缀与不变后缀。

若有绕过 \(z\) 的下游入口，或者资源在 \(z\) 仍有多种状态，单个标量摘要便不足。“任务时段已结束”也不能消除其前缀成本优势。

这是条件性结构方向，来源新颖性未检查，分类为 `STILL_OPEN`。本轮两个完整状态图均没有 source/sink 以外的全图必经状态；该检查**不排除任务局部同步出口**，后者尚未搜索。

## 4. 探针协议与证据范围

### 4.1 完整状态图与预算

按 A2 枚举所有源可达状态及合法转移，随后删除不能到达合法终点的状态，得到与对偶无关的固定 DAG。保留全部转移，每轮同状态取最低成本前缀。未采用跨资源支配、双向搜索、完成界或其他特殊多项式算法。

预设构图预算为 500,000 个源可达状态或 3,000,000 条边。按完整实例执行；触及预算即报告中止，不截取部分图充当原实例。触发检查在处理一个原始任务后执行，所以记录值可能略超过预算。

### 4.2 两类对偶序列分开记录

**闭环 RMP 序列：** 仅 s2_t90。以官方解的 14 个可行 duty 为 seed，外置研究测试通过 SciPy/HiGHS 解覆盖 LP；定价使用本地 Python DP。每轮只加一条全局最负列，不稳定化、不删列、不分支，最多 200 轮。覆盖约束写为 \(-Ax\le-1\)，取 \(\pi=-\text{ineqlin.marginals}\ge0\)。

只有冷 DP 决定加入的列；repair 是不影响主循环的逐状态距离核验。冷 DP 按固定前驱状态、动作、扩展边顺序，以严格 binary64 `<` 留下首次达到最小值的前驱。该合同固定一条可重放轨迹，未执行两个可相互偏离的 CG 算法。

**人工压力序列：** 对两个完成构图的实例，固定零对偶参考树，依次查询统一对偶 12,000、交替坐标 6,000/18,000、最早任务单坐标 100,000、回到零。它只验证语义与失效形状，不能用于声称常态 RMP 寿命。

### 4.3 修复与 epoch 策略

沿用 note28：查询全部当前负余量弧 \(B\)，取其头部后继闭包 \(A\)，按拓扑顺序使用全部内部及外部入边重算。分组查询结果还与直接余量扫描逐边核对。

闭环采用“发现 \(B\ne\varnothing\) 就在本轮后重建树/索引”的严格策略。note28 的正确性允许继续使用非最优参考树，这一策略的寿命不能解释为数学上必须重建的频率。

### 4.4 独立语义核验

独立 DFS 直接枚举原始连接路径，保存所有休息开始累计量 \(q\)，在终点判断是否存在有效见证；它不调用 A2 的扩展转移或 DP 可行性函数。三个诱导切片分别枚举出 18、2、37 条合法 duty，在三个整数对偶点下，枚举最小值等于 DP，所选 DP 路径属于枚举最优集，repair 距离误差为零。

前两个切片取按开始时刻排序的前 18 个任务。s6_t450 的这一前缀没有合法 duty，因此明确记录该结果，改取最长官方 duty 的任务诱导图作为语义检查。切片只是异构实现核验，不能代替完整原实例最优性 oracle。

两个完成构图实例的全部官方 duty 均独立复核了覆盖、成本与休息可行性，成本分别为 748,080 和 1,441,980。官方可行解用于模型对齐，不作为定价最优性真值。

### 6.1 s2_t90：200 轮真实闭环，但尚未收敛

| 指标 | 本轮结果 |
|---|---:|
| \(|A|/N\) | 中位数 61.27%；范围 15.11%–71.38% |
| 重算内部＋外部入边 / \(M_H\) | 中位数 79.56%；范围 34.26%–88.08% |
| \(K\) | 中位数 7,012；范围 6,219–8,270 |
| 全部组差分支持总量 | 中位数 60,661 |
| 外部边界前驱状态数 | 中位数 2,993.5 |
| 边界前缀特征支持量 | 中位数 11,739 |
| 严格重建策略的 epoch 长度 | 200 个 epoch，全部为 1 |
| repair 与冷 DP 的最大逐状态距离误差 | \(4.41\times10^{-9}\) |

第 200 轮 RMP 目标约为 748,080，仍有最小检验数约 \(-15,665.73\)，状态为 `iteration_cap`。这不是完整 root LP 终止；不能以目标值暂时不动推断收敛。仓库给出的该实例根下界为 745,680，本轮没有复现它。

序列确由 RMP 与定价闭环产生，但采用未稳定化、单列加入的简化合同。该合同可能放大退化和对偶跳跃；作者使用的稳定化、多列、列管理及双向定价均未复现。结果可以削弱当前索引配置，不能否定所有对偶稳定化下的增量定价。

### 6.2 操作计数，不能换算为时间倍数

令 \(\operatorname{nnz}_{\rm sig}\) 为每轮所有组的支持量，\(L_{\rm bin}\) 为实际二分比较次数，\(V_{\rm close}\) 为闭包遍历边次数，\(E_{\rm in}\) 为修复全部入边，\(Q_{\partial}\) 为不同外部边界前驱的树前缀支持量。记录

\[
W_{\rm report}=\operatorname{nnz}_{\rm sig}+L_{\rm bin}+|B|,
\]

\[
W_{\rm maint}=W_{\rm report}+V_{\rm close}+|A|+|E_{\rm in}|+Q_{\partial},
\qquad
W_{\rm cold}=S+N+M_H.
\tag{A6}
\]

这将算术、比较和图访问按单位权合计，只是机制诊断。\(W_{\rm maint}\) 还未计拓扑排序、需要的动作权重求值、输出、索引存储与 epoch 重建；分组和前缀投影也可以有其他优化实现。A6 不是运行时间预测，也不是所有算法的复杂度下界。

s2_t90 的 \(W_{\rm cold}=37,740\)，仅报告操作中位数就达 77,116.5；\(W_{\rm maint}/W_{\rm cold}\) 范围约 2.56–3.88，中位数 **3.45**。这些数支持“当前分组查询及修复配置没有显示较小操作规模”；不能写成“实测慢 3.45 倍”。

脚本为语义核验计算全部参考边权和距离，没有实现按需物化的快速版本。任何脚本总时长均不用于方法比较。

### 6.3 s3_t168：人工回放中的另一项负证据

四次人工查询的 \(|A|/N\) 为 0%–19.09%，比上述闭环小；但 \(W_{\rm maint}/W_{\rm cold}\) 仍约为 1.33–2.62。最后回到零对偶时 \(B=A=\varnothing\)，全组投影与定位依然有成本。

这进一步说明“小修复区”与“低总维护成本”是两个不同条件。四个人工点不提供平均运行性能或真实 epoch 寿命证据。

1. 确认目标应用的定价成本占比，并在稳定化、多列生成的实际 RMP 合同下检查对偶轨迹；当前未稳定化单列序列仅作压力和失败机制证据。
